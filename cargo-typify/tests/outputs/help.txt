cargo command to generate Rust code from a JSON Schema or OpenAPI document

Usage: cargo typify [OPTIONS] <INPUT>

Arguments:
  <INPUT>
          The input file to read from: a JSON Schema document or an OpenAPI (3.0.x, 3.1.x, or 3.2.x) document, in JSON

Options:
  -b, --builder
          Whether to include a builder-style interface, this is the default

  -B, --no-builder
          Inverse of `--builder`. When set the builder-style interface will not be included

  -d, --additional-derive <derive>
          Add an additional derive macro to apply to all defined types

  -a, --additional-attr <attr>
          Add an additional attribute to apply to all defined types

  -o, --output <OUTPUT>
          The output file to write to. If not specified, the input file name will be used with a `.rs` extension.
          
          If `-` is specified, the output will be written to stdout.

      --crate <CRATES>
          Specify each crate@version that can be assumed to be in use for types found in the schema with the x-rust-type extension

      --map-type <MAP_TYPE>
          Specify the map like type to use

      --unknown-crates <UNKNOWN_CRATES>
          Specify the policy unknown crates found in schemas with the x-rust-type extension
          
          [possible values: generate, allow, deny]

      --optional-properties <OPTIONAL_PROPERTIES>
          Specify the representation of non-required object properties: "explicit" represents every one as an Option<T>
          
          [possible values: collapsed, explicit]

      --all-of-strategy <ALL_OF_STRATEGY>
          Specify the interpretation of allOf constructions: "compose" embeds referenced base types as flattened members
          
          [possible values: merge, compose]

      --open-enum-variant <name>
          Give every plain string enum a catch-all variant of this name that losslessly round-trips values outside the documented set

      --no-schema-in-docs
          Limit generated doc comments to the schema's description rather than embedding the whole JSON schema

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
